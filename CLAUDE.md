# NEXTJS PROJECT

Keep in mind this project is made on Nextjs V16, all you need build check package.json and pnpm-lock.yaml.
Must use pnpm to install dependencies.

## Styles

This projects handle tailwindcss for styling, if you need colors, fonts, spacing, you can check the tailwind.config.ts file and the lib/content.ts file for content.

## Images

Images must to be optimized first before to use it.
